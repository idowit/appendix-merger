# Appendix Merger

Language for assembling a primary document and its supporting material into one finished PDF.

## Language

**Main Document**:
The primary document that appears first in an Appendix Compilation. An Appendix Compilation has exactly one Main Document.
_Avoid_: Primary file, first file

**Appendix**:
A supporting document that follows the main document and is identified by an ordered appendix number and title.
_Avoid_: Attachment, extra file

**Appendix Compilation**:
The ordered working set containing one Main Document, its Appendices, and the settings used to produce a Finished PDF.
_Avoid_: Project, merge

**Quick Merge**:
A secondary workflow that combines ordered source documents without assigning Main Document or Appendix roles.
_Avoid_: Appendix Compilation, project

**Finished PDF**:
The generated output of either workflow. An Appendix Compilation adds its table of contents, covers, markers, and numbering; a Quick Merge only applies options selected for that workflow.
_Avoid_: Result file, merged file

**Compilation File**:
A locally saved file that can reopen an Appendix Compilation, including its documents, ordering, titles, and output settings.
_Avoid_: Cloud project, backup

**Output Style**:
The selected visual treatment for appendix covers and the table of contents. The supported styles are Polished and Minimal.
_Avoid_: Template, theme

**Appendix Marker**:
The optional label placed on appendix pages to identify their appendix number.
_Avoid_: Stamp, badge
