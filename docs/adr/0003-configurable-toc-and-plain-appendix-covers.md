# Make generated appendix sections configurable and visually plain

Allow an Appendix Compilation to omit its Table of Contents and Appendix Covers independently. When included, the Table of Contents uses a plain monochrome table with the Appendix, document name, and page-range columns; the range includes an Appendix Cover as the first page of its Appendix. Appendix Covers contain the appendix label, document title, and complete page range without decorative graphics. Continuous black page numbering starts on the first page of the Finished PDF, appears at a fixed bottom-left position, and includes generated sections. Optional Appendix Markers use a larger monochrome label at a fixed top-left overlay position without resizing source pages. Existing drafts and version 1 Compilation Files that predate these options default both generated sections to enabled.
